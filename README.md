This is a CLI (Command-line interface) application that is an interactive accounting ledger; it allows the user
to track transactions, manage deposits and payments, and view detailed reports from the terminal. 

The application reads from a CSV file and writes new inputs from the user into the file as well. Showing new files
that have been added to the bottom and also catching any mistakes that have been input incorrectly so that 
the application can loop back and ask the user for the correct format. 

To run the project 

 Home Screen Options
- D) Add Deposit — Prompts for transaction records and logs user savings.
- P) Make Payment — Captures negative expense amounts.
- L) Ledger — Switches to Ledger screen
- X) Exit — Safely shuts down.

 Ledger Screen Options
- A) All — Prints out all historical entries loaded into active list memory.
- D) Deposits — Searches for deposits based on amounts
- P) Payments — searches for payments 
- R) Reports — finds specific searched queries.
